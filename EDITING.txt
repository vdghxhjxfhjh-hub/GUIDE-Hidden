위브웍스 특수복 / 수정 안내

index.html: 회사 이름, 소개, 제작 분야, 납품 사례, 상담 안내
content.js: 외부 이미지 URL과 기술 문서 7건
style.css: 디자인
app.js: 이미지 자동 맞춤, 문서 열람, 검색 및 분류

content.js의 WW_IMAGES에서 src에 외부 이미지의 직접 HTTPS URL을 붙여 넣으세요. 공유 페이지 주소가 아닌 이미지 파일 주소를 사용합니다.
예: hero:{src:'https://your-domain.com/main.png',ratio:'landscape',fit:'contain',alt:'제작 공정'}
landscape = 1216×832 / portrait = 832×1216 / square = 1024×1024
auto = 원본 비율 자동 적용
contain = 전체 이미지 보존 / cover = 영역을 채우고 넘치는 부분 자르기
비어 있거나 로딩에 실패한 사진은 회색 배경으로 남습니다.

문서는 세계관용 초기 초안입니다. WW_DOCUMENTS에 같은 구조로 추가할 수 있습니다.
납품 사양의 L/S 구분은 추후 단서 확장을 위한 초안이며 개인별 지급 명단은 아직 없습니다.
업체는 외피 제작과 지정 조립을 담당하고 GUIDE가 내피를 공급한다는 설정입니다.
실제 연락처 및 접수 기능은 아직 없으며 화면에 추후 안내로 표시했습니다.

숨겨진 메시지: Ctrl+Shift+I (페이지에 키보드 초점이 있을 때).
첫 재생 완료 후 같은 브라우저에 완료 상태를 저장합니다. 이후에는 코드만 재생합니다.
저장소를 사용할 수 없는 환경에서는 현재 페이지 동안만 완료 상태를 유지합니다.
signal.js: 메시지/코드/타이핑 속도. signal.css: TV 종료 및 복귀 연출.
테스트 초기화: 사이트 데이터의 ww.signal.seen.v1 항목 삭제.
브라우저/운영체제가 단축키를 먼저 처리하는 환경에서는 웹페이지가 가로채지 못할 수 있습니다.
키보드 없는 모바일에서는 이 기믹을 실행할 수 없습니다. 공개 힌트나 대체 버튼은 넣지 않았습니다.
이 메시지는 사전 기록이며 실시간 채팅/입력이 아닙니다. 발신자 표시는 없습니다.
